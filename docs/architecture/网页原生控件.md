# 网页原生控件

运行窗口为 GeckoSession 注册 WebPromptController，接收单选、多选、alert、confirm、prompt、文件、颜色及日期时间请求。控制器将当前请求保存为 Compose 状态，RuntimeWindow 在项目尺寸、边距和圆角之外绘制弹层，普通窗口和悬浮窗口共用同一实现，不启动额外 Activity，也不暂停网页会话。

WebPromptRequest 统一完成确认、取消及内核撤销，每个请求只完成一次。页面动态更新选项时切换到新提示对象并重建选择草稿，禁用选项组的状态传递给子项。会话关闭先取消提示，再拆除代理。返回和手表边缘返回优先取消当前提示，关闭提示后保留网页；点击遮罩仅拦截触摸，不关闭提示。

单选点击有效叶子选项立即回传，多选在弹层中保留草稿，确定后回传，允许空集合。alert 关闭后继续，confirm 确认返回 true、取消返回 false，prompt 取消返回 null。

日期时间使用并排滚轮，支持 date、month、week、time、datetime-local；日期时间分为两个页签，秒和小数秒按默认值、最小值及步长需要显示，确保 min 的秒级步进基准可编辑。滚轮只绘制可见数字，停止滚动后更新草稿；滚动时禁用日期时间切换，滚轮离开组合前保存最接近中心的值。日期使用本地日历语义；范围与步长以日、月、周或秒计算，支持跨午夜时间范围和小数秒，清空后交由网页自身处理 required 校验。颜色默认显示预览与色板，RGB 滑条及六位十六进制输入折叠在精确调整中。

文件选择默认浏览设备共享存储，也可切换到项目资源。没有权限只显示提示，不主动打开授权页面或系统文件选择器。accept 用于扩展名、MIME 及通配类型过滤；支持单个文件与跨目录多选，切换存储来源时清空选择。确认时再次检查文件存在且可读，再将本地 file URI 交给 Gecko 的 FilePrompt，不复制文件。设备目录复用既有存储授权及目录边界校验。文件夹上传与直接调用相机采集未接入。

普通运行窗口的弹层覆盖承载屏幕，系统悬浮窗口的弹层位于该悬浮窗口内，遮罩阻止点击穿透到网页，正文可滚动，操作栏固定。手机选择器采用底部面板，提示、确认与文字输入使用居中对话框；折叠屏展开后居中限宽。手机选择器配色跟随系统深浅色，Android 12 及以上使用系统动态配色。alert、confirm、prompt 则复用应用的 AppDialogContent、AppTextField 和 DialogAction，与项目设置等页面统一为白底细边框、20dp 圆角、右上角关闭及蓝灰色图文操作；AppDialogContent 不创建系统窗口，普通应用弹窗由 AppDialog 包装它，网页提示仍在当前界面绘制。手表面板占满承载屏幕，使用黑底，不添加外层圆角卡片；只有内容按表盘尺寸留出圆弧安全区，底部采用 44dp 的取消、确认图标按钮。文件来源和日期时间使用统一分段控件，单选、多选使用标准选中标记。键盘出现时通过 imePadding 缩小内容区。预览项目仅保存在本机模拟器数据中，不属于应用源码、内置项目或发布附件。

弹层出现时不调用 requestFocus。当前 GeckoView 内核在 select 元素的 blur 事件中撤销选择提示，month 和 week 也有对应的失焦处理；把焦点从网页强制移到 Compose 会导致菜单刚出现就消失。输入框只在用户实际点击输入时获取焦点。

资源开销与取消：没有活动请求时不组合任何提示界面，仅保留会话代理和少量请求状态。目录枚举、类型过滤、排序和确认前检查均在 IO 线程进行，关闭选择器取消其协程；系统单次目录枚举和仓库同步调用返回后再检查取消。设备目录扫描与排序逐项响应取消，不读取未展示的文件大小，项目目录不重复排序。选中记录保留资源来源，项目文件消失不会回退到同名全局模板。滚轮仅监听滚动状态变化，停稳提交数值后才恢复确认按钮，数值已经对齐时不再调用 scrollToItem。
