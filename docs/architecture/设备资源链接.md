# 设备资源链接

ScriptDeviceResources 随运行文档提前注入。img.src 和 img.setAttribute 在赋值时将 device:/ 路径编码为同源的 /__sview_device 请求；文档 MutationObserver 只监听节点新增和 src 变化，补充解析器生成的静态 HTML、innerHTML 和动态插入节点，不轮询。页面恢复时重新监听。属性读取可以得到内部映射地址。

映射端点位于既有的回环 ProjectServer 内，先通过运行会话认证，再核对 Host、Origin 和请求来源。复用 StoragePaths 与 DeviceStorage 校验设备权限、路径边界和符号链接，只允许图片 MIME，以 32 KiB 缓冲流式返回。资源不缓存，不作为可执行网页使用，SVG 直接导航受 sandbox 限制。

链接保留原始 href，文档点击监听识别 device:/ 并调用内部 resource.openDevice。图片复用 ImagePreviewController；其他文件以及 SVG 通过独立的 DeviceFileProvider 授予单文件临时读取权限，并交给系统应用。Provider 不对外导出，禁止写入和删除，没有处理应用时向项目日志报告错误。项目结束会关闭链接调用入口。

范围为常规文档中的 img.src 和 a.href；不扩展 srcset、CSS 资源或自定义协议导航。设备路径按原始文件名编码，不能预先按 URL 编码后再传入。
