# TCP 端口扫描

`sview.network.scanPorts(options)` 同步返回只读任务句柄 `{ result, close }`，下一微任务开始参数校验和原生调用。`onStart` 在解析成功后、首条探测结果前触发；逐条 `onResult` 按完成顺序交付。`onProgress` 合并到约 200 毫秒一次，终态前补发最终统计。回调异常仅记录日志，不改变扫描结果；异步回调不阻塞扫描。

正常完成和主动关闭分别以 completed、closed 汇总完成 result。任务失败先调用 onError，再发最终进度与 onClose，result 拒绝并携带 summary。所有路径最多一次 onClose；启动失败也有终态，但不触发 onStart。close 幂等，停止新探测并关闭在途 Socket，等待原生清理和网页结束通知；未完成或尚未交付到有界队列的结果不纳入统计。网页销毁后的回调不能保证执行。

PortScanOptions 负责严格校验、展开和去重，PortScanTask 负责连接和结果队列，PortScanApiBridge 负责窗口内句柄及生命周期。每窗口最多一个未消费完的任务，应用最多四个运行任务、32 个在途连接。手机默认并发 16，手表默认 4；不持有唤醒锁、不重试、不创建常驻探测线程。域名仅解析一次，使用系统返回的第一个地址。解析最多等待 10 秒，系统 DNS 无法立即中断时丢弃迟到结果；共享解析线程池有界且空闲回收。

结果通过现有鉴权系统接口按需读取，每次最多 32 条、等待最多一秒，原生队列最多 64 条。队列满后探测线程等待消费者，不累计全量结果；网页超过 30 秒不读取且队列背压时，任务以 CONNECTION_LOST 结束。读取走慢通道，close 走独立控制通道。终态单独保存，不依赖队列腾出空间。窗口释放停止所有任务，pagehide 尝试停止并丢弃句柄。全局任务名额在原生完成时归还。

Socket 仅执行 TCP connect 并立即关闭，不发送协议数据。状态按超时异常和 Android 底层 errno 区分，只有 ECONNREFUSED 标记 closed，不能靠异常文案猜测。无法归类的连接失败标记 error，权限错误终止整个任务。汇总只保留开放端口和五类计数；通道故障时网页提供已收到的部分汇总，不冒充完整结果。
