# 文件与目录复制

copy(source, destination, options?) 使用现有存储控制通道，不经过 JavaScript 传递文件正文。来源与目标沿用 StoragePaths 解析与权限检查，目标明确表示最终路径。只允许 overwrite 覆盖普通文件，目录仅复制到不存在的目标。

ScriptStorage 在共享占用表中预留来源与目标，拒绝与已有保存或复制操作冲突。分块复制期间释放全局锁，其他运行窗口可以继续读取或操作无关文件。关闭状态与线程中断在每块读取、目录遍历和提交前检查。

StorageCopy 在目标父目录创建登记过的暂存文件或目录，64 KiB 缓冲复制，遍历不跟随符号链接，特殊文件直接报错。提交前再次检查路径和目标冲突。文件覆盖采用同文件系统原子替换，不支持时保留旧目标并报错；目录不合并。项目 main.js 或 index.html 变更复用仓库刷新逻辑。

TemporaryFiles 新增目录登记与不跟随链接的递归清理。正常完成或失败释放记录，意外退出的暂存内容由现有缓存清理回收。自动创建的父目录不作为暂存目录删除；复制不保证外部应用同时修改来源时的一致快照。
