# 网页代码补全

保留原有 textarea 编辑器。app.js 只在编辑器创建、页面切换和按键分发时连接独立模块，completion.js 管理浮层、输入法、键盘和定位，completion-engine.js 负责纯文本上下文和候选计算。插入前记录原选区，再调用原 commitText，一次补全对应一条撤销记录，保存逻辑不变。Tab / Shift+Tab 关闭候选并继续原缩进操作。

首次触发时才读取本地 completion-css.json 和 completion-sview.json；加载失败不影响编辑，手动触发可重试。输入合并 90 毫秒，只有当前 textarea、文本、选区和请求代次都一致时才显示结果。页面切换销毁监听、计时器、定位镜像和浮层。滚动、失焦、选择文本和输入法组合期间关闭候选。

CSS 字典从固定版本的 MDN data 生成，覆盖非废弃、非厂商前缀的属性、值语法、规则、单位与伪选择器。原始 CC0 许可随应用保留。S View 候选从现有 Kotlin 接口帮助生成，增加或修改接口时运行 scripts/generate_editor_completions.py；同步更新静态资源，无需运行时依赖 Kotlin 帮助页面。

JS 按白名单枚举浏览器原生对象的属性描述符，不执行待编辑代码，不求值用户表达式。支持明确的数组、字符串、new 构造及 DOM 查询变量；不推断任意业务对象、跨文件引用或复杂返回类型。轻量词法扫描屏蔽注释、字符串和常见正则字面量，模板字符串插值中恢复 JS；HTML 仅在 script、style 与 style 属性中切换语言。复杂语法的识别不是完整解析器。

每次最多展示 80 个候选，当前文件标识符最多收集 2000 个；超过 200000 个字符时不启用补全，避免大文件输入卡顿。候选文字通过 textContent 输出，浮层只替换光标前缀，已有括号和冒号不重复插入。镜像仅在展示时测量位置，不创建项目运行环境，也不向外网发送代码。
