# 本地热点

ScriptApi 为 `sview.network.hotspot()` 创建异步对象，名称与密码只读，close 复用在途 Promise，失败后允许重试。控制调用复用项目系统接口通道的 Origin 与会话认证，不把热点控制混入 HTTP 上传下载任务。

HotspotApiBridge 在主线程申请 WifiManager.startLocalOnlyHotspot，接口线程最多等待 30 秒。每个窗口保存预约及随机 ID，close 只匹配当前窗口和当前预约，旧对象不会关闭新热点。进程级占位只在主线程访问，避免多个项目争用系统每应用一个申请的限制。

RuntimeApiBridge.close 在正常项目关闭、异常终止和应用退出时释放预约。退出应用已有的 RuntimeAppExit 关闭窗口流程会先释放资源再结束进程，进程异常结束时由 Android 清理 Binder 预约。后台化不主动释放已运行项目的热点。

系统公开 API 无法在尚未返回预约时撤回申请，因此超时、窗口提前关闭都会将请求标为取消并保留占位；成功回调迟到时立即关闭预约，失败或停止回调释放占位。不能提前清空占位并重新申请，否则旧请求可能在新请求开始后留下热点。

使用 API 30 起的 SoftApConfiguration 获取配置，旧系统读取预约的 WifiConfiguration。Android 13 起申请 NEARBY_WIFI_DEVICES；旧系统沿用精确位置权限和位置服务检查。项目已有 Wi-Fi 扫描能力，因此不声明整个应用 neverForLocation。仅调用本地热点公共 API，不控制互联网共享，不修改系统热点配置，也不强制停止其他应用持有的共享热点。
