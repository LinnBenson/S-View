# 工作区与运行时

BrowserEngineConfiguration 关闭内容进程预启动，将普通内容进程数设为 1，并关闭独立扩展进程；保留沙箱和站点隔离。配置在运行准备阶段写入私有目录，后续会话复用；升级 Gecko 时需复核内部偏好项。

WorkspaceModel 通过 awaitReady() 发布初始化完成或失败结果。小部件悬浮服务和手表同步服务直接挂起等待，不依赖 Compose 快照的界面派发，也不轮询。等待方取消不会取消共享初始化。

HTTP 与 FTP 共用 LocalEditorAddresses，只绑定启动时可用的局域网 IPv4 地址，不监听 IPv6、通配地址或回环地址；网络切换后需要重新启动服务。

桌面入口使用 AppWidgetProvider 与 RemoteViews，不运行浏览器。每个小部件独立保存 16 个项目槽位；根据桌面提供的尺寸生成 1–4 行、1–4 列布局，Android 12 及以上提供尺寸映射，较旧系统提供横竖屏布局。配置页保存后更新对应实例，项目配置保存后刷新全部实例，不设置周期刷新。

点击槽位通过私有 WidgetLaunchActivity 按当前悬浮窗授权分流。普通运行签发一次性进程内令牌交给首页，公开首页不接受外部任意项目 ID。悬浮运行使用 specialUse 前台服务及 TYPE_APPLICATION_OVERLAY。网页矩形和可选遮罩是两个窗口，先附着遮罩，完全透明时只保留网页矩形；尺寸依据屏幕最大安全区域计算，避免百分比相对当前悬浮窗口反复缩小。复用 RuntimeWindow、项目资源服务与系统接口。WorkspaceOwner 让首页、配置页及悬浮服务共用工作区模型和写入队列。锁屏、撤销授权、关闭或替换窗口时销毁 Compose、GeckoSession 与资源服务。NFC reader mode 仍需要 Activity，悬浮宿主中返回明确错误。

应用界面使用 Jetpack Compose，网页使用内置 GeckoView。手机窄屏通过标签切换代码、资源与全局变量，宽屏保留资源侧栏。运行窗口按当前可用区域裁剪尺寸，不修改项目保存的原始宽高。宽高支持 dp、px 和百分比，旧版无单位尺寸按 dp 读取。GeckoView 使用 TextureView 后端，使网页内容跟随窗口的 20 dp 圆角裁剪；关闭按钮的视觉尺寸为 26 dp，点击范围为 44 dp。表单弹窗使用统一自定义组件，并为键盘与安全区域预留空间。

## 私有存储

- `files/categories.json` 独立保存分类名称与顺序，空分类不会丢失；删除分类不会删除项目，未设置分类的项目统一从“全部”查看。
- `files/projects.json` 保存项目顺序、分类、颜色、置顶状态、窗口尺寸与变量。
- `files/projects/<项目 ID>/files/` 保存项目独立的脚本和资源。
- `files/templates/` 集中保存全局模板；默认 `index.html` 从 `/main.js` 加载项目脚本。默认 CSS 独立保存在 `global.css`，新建项目的引用列表自动包含 `/global.css`，通过引用占位符生成 link 标签。

资源解析先查项目目录，再查模板目录。同名项目文件只覆盖当前项目。资源列表标注继承的全局模板；在项目编辑器中保存该文件会生成项目副本。设置中的模板页支持列表、编辑、导入和删除。index.html、global.css、global.js、jquery-4.1.0.js、lucide-1.77.0.js、alpine-3.17.5.js 为系统模板，存储层禁止删除；同名导入不覆盖已有文件。模板编辑直接修改全局文件。受保护的系统模板提供还原按钮，经确认后使用当前安装包中的同名资源原子覆盖，并同步编辑缓冲与入口缓存；项目副本不受影响。文件读写先规范化路径，再检查目录边界。

## 运行

运行时创建仅监听 `127.0.0.1` 的资源服务，为绝对资源路径提供统一来源。入口请求使用随机令牌，后续请求依赖 HttpOnly、SameSite Cookie。系统接口通过受保护的 POST /__sview_api 桥接：校验会话凭据、精确 Origin、自定义请求头和 JSON 类型，请求体上限 64 KB；拒绝响应不下发会话 Cookie。JS 变量在入口脚本前注入，数组使用 JSON 解析，支持对象数组。

GeckoRuntime 首次运行时初始化并在进程内复用。每次运行创建独立 GeckoSession，关闭窗口时关闭会话、监听套接字和资源线程。应用进入后台时会话置为非活动。悬浮运行使用前台服务，运行窗口可保持亮屏；不持有额外唤醒锁。

## 性能约束

文件扫描与保存通过 IO 队列执行，配置和脚本均原子替换。输入采用 650 ms 防抖，切换文件和后台退出前立即提交；运行前等待当前脚本写入。项目网格和资源列表按需组成。

编辑器的撤销历史限制为 80 项及累计 50 万字符。超过 10 KB（UTF-8）的内容停用语法高亮；超过 2 MB 的文件不在编辑器中打开。图片按显示尺寸采样。控制台只保留最近 200 行，网页日志由事件触发批量发送，无日志时没有轮询。

Lucide 图标转换为 Android 矢量资源，运行时不解析 SVG。原始图标及许可证位于应用资源目录；代码字体为 JetBrains Mono。

页面标头统一为 56 dp，标题字号与返回按钮留白共用组件。权限使用二级页面，界面外观与编辑器样式固定。项目和分类的拖动实时更新内存顺序，卡片提供抬起、跟随手指、让位与落位动画，拖动结束后仅保存一次；边缘滚动只在拖动期间逐帧检查。

拖动网格占满列表可用区域，避免少量项目时视口按内容高度收缩。项目和分类长按开始拖动时触发一次系统触感反馈，遵循系统设置；拖动保留缩放和落位动画，不绘制阴影。

运行时先展示窗口，再初始化网页引擎。入场使用 220 毫秒的淡入与轻微缩放，点击关闭按钮或遮罩时触发系统触感反馈，返回键与脚本关闭不触发；关闭在 160 毫秒退场动画后释放会话。加载指示由 GeckoView 页面开始、结束回调驱动，完成后淡出，后台不保留转动动画。

项目引用项保存在项目配置中，保存时仅替换 index.html 中的 `<!-- sview:references -->` 占位符，按列表顺序生成 script/link；没有占位符时不插入引用。支持项目路径和 HTTP/HTTPS 地址；远程 HTTP 是否可访问仍遵循应用网络安全配置。JS 同步、defer、async、module 保留浏览器原生执行时机，延后或异步资源不保证早于 main.js 执行；CSS 默认阻塞样式加载，非阻塞使用 media 切换，可能短暂显示未应用样式的页面。模板文件不会被改写。

语法高亮使用 Prism4j 2.0.0，仅生成 JavaScript、HTML/XML、CSS、JSON 四类语法。解析在串行后台调度器执行，文本合并 90 毫秒输入。超过 10 KB（UTF-8）立即显示纯文本，不创建语法解析任务；未知文件类型按纯文本处理。高亮结果必须与当前原文一致才应用，避免异步返回导致光标范围错误。

项目日志保存在 `files/projects/<id>/runtime.log`，与网页资源目录隔离。删除项目会删除该文件，删除后到达的日志不会重建目录。打印、脚本异常、未处理 Promise 和资源加载错误统一写入。后台队列最多保留 64 批，满载时不再接收新的待写消息；单批最多 16 KiB。文件超过 2 MiB 时裁剪到最近约 1 MiB，页面读取最近 256 KiB，导出当前文件的全部内容。

内置 GeckoView 原生库继续保持页对齐、未压缩格式，由系统直接映射，避免安装后额外解压一份。应用图标按最高密度所需的 432 像素生成无损 WebP；设计原图不参与运行时解码。库只在首次编辑或运行时初始化，首页不预热浏览器或语法引擎。

全局库文件来自应用 assets，jQuery、Lucide 和 Alpine.js 保留官方压缩代码。初始化仅复制缺失的模板文件，已有文件保持不变。Alpine.js 3.17.5 按项目引用加载，快速添加默认使用 defer；不自动加入已有项目，未引用时没有初始化开销。main.js 注册 Alpine 扩展时应监听 alpine:init 事件，不要重复调用 Alpine.start()。内置目录同时用于模板删除保护、局域网编辑器保护和手表同步完整性检查。

项目资源列表不展示入口脚本 main.js 和内置引用库；代码页仍可编辑 main.js，引用项管理库的加载方式。文件读取和运行时路径解析不受列表过滤影响。

引用项复用长按拖动状态，排序在内存中即时更新，松手后串行保存，模板按保存的列表顺序生成标签。拖动触发系统触感，使用让位和落位动画，不设置阴影。异步脚本仍遵循浏览器自身的执行时机。

项目日志列表采用无图标的紧凑行并显示实际文件大小。列表搜索项目名称，详情在后台搜索整份保留日志，输入合并 180 毫秒，最多返回约 128 Ki 字符，避免一次渲染完整大文件。

运行产物位于项目私有根目录的 runtime/index.html 和 runtime/main.js。保存入口、主脚本、全局变量或引用配置后生成；其他文件无需复制。全局入口修改只重建没有项目入口覆盖的项目。初始化在运行缓存未就绪时补齐产物，运行前等待当前待保存内容与配置队列完成，HTTP 入口请求只流式读取生成文件。signature 包含生成器修订号、源文件元数据与变量/引用配置，未变化时复用产物；修改生成规则时必须递增 RuntimeDocument.REVISION。源文件保存强制刷新对应产物，避免同长度快速修改漏判。

全局变量使用 <!-- sview:variables --> 占位符；引用使用 <!-- sview:references -->。默认模板将变量放在引用之前，日志桥独立置于 head 开头。用户可以自行调整标记位置或删除。生成文件不展示在项目资源列表，删除项目时一起清理。

运行产物分别保存入口与主脚本签名。只改变量、引用或入口时不重写主脚本，只改主脚本时不重新拼接入口。保存明确传入变化路径，因此同长度、同时间戳的快速修改仍会更新。项目名称、颜色、尺寸和排序变化不触发运行文件重新生成。

启动使用 runtime-ready 就绪标记，只有首次迁移、生成器版本改变或上次保存未完成时才逐项检查；普通启动不扫描各项目运行目录。影响产物的写入之前使标记失效，全部成功后恢复。若进入保存时已有待恢复状态，局部保存不会恢复标记。每次运行仍只检查选中项目，保证缺失产物可以补齐。

日志在有消息时最多合并 150 毫秒或 32 条消息，再按项目集中追加文件。接收时间独立保留，控制台每批只更新一次。空闲等待通道消息，没有周期轮询。查看、导出、清空、关闭运行窗口或应用进入后台时使用刷新屏障，先提交已有日志。新建项目默认窗口为 360dp × 80%。

运行窗口先绑定 GeckoView 再加载入口，纹理首帧前使用与窗口底色一致的覆盖。加载遮罩等待页面加载与首次合成都完成后淡出，避免露出尚未绘制的缓冲区；后台暂停加载动画。

系统接口统一由 ScriptApi 注入全局 sview 对象，在用户脚本执行前可用。帮助页按系统、网络、交互、脚本、工具分类，首级显示接口名称及简短用途列表，标题栏搜索可按名称与用途筛选，点击后进入用途、参数、返回值及示例详情；传入参数、返回结果和调用示例分区展示，参数类型、必填状态和默认值独立列出；返回保留所选分类。system 提供提示、通知、震动、应用与链接跳转、剪切板、分享以及设备状态查询；interaction 提供关闭和调整窗口大小。SystemApiRequest 校验方法与参数，SystemApiBridge 分发到主线程 Toast 和脚本通知渠道。通知权限由权限页申请或跳转系统设置管理，运行脚本不绕过授权。关闭窗口释放桥接实例并取消未执行的 Toast；通知本身交给系统管理。接口调用为 Promise：Toast 完成无值，通知返回编号，失败拒绝。

编辑页运行按钮左侧提供系统接口帮助弹窗，复用设置中的帮助页面与导航，关闭后保留编辑器状态。列表和详情可复制完整接口名，示例区可复制完整代码及换行。

NFC 由 `NfcApiBridge` 管理前台 reader mode，`ScriptNfc` 保存网页回调。监听与 monitor 共用 `WindowEvents` 的 SSE 连接，建立连接后才请求启动；JS 将早到的消息暂存到启动响应之后，保证 onStart 先执行。启动与关闭命令串行发送，监听编号隔离不同会话，重复关闭不会再次触发 onClose。Activity 暂停时关闭 reader mode 并释放 NFC 状态广播，窗口释放时取消排队调用。只允许一个原生监听，防止多个窗口相互覆盖 Activity 的 reader mode。

`NfcTagData` 解析系统发现标签时读取的 NDEF 缓存，不在主线程执行标签连接或额外读写。文本记录支持 UTF-8、UTF-16，链接使用系统 NDEF 解码，未知记录保留字节。原生 JSON 中的字节数组在 JS 中恢复为 Uint8Array。重复发现以标签 ID 和技术列表去重，时间使用单调时钟，最多保留 128 个标签的最近回调时间；不会以定时轮询重复读卡。没有 NDEF 消息时仍返回标签 ID 和技术列表，ndef 为 null。

系统接口的完整参数、返回值和可复制示例见应用「设置 → 系统接口」。位置与附近设备权限在权限页管理，定位仅在前台单次执行，完成、超时或退到后台即取消。`sview.interaction.resize(width, height, persist = false)` 接受带 dp、px、% 的尺寸，默认仅改变本次窗口；第三个参数为 true 时写入项目配置，保存完成后返回。`sview.interaction.close()` 关闭并终止当前运行，不提供等待函数。

项目网页存储按项目隔离，localStorage、IndexedDB 和持久 Cookie 在再次运行时保留。sessionStorage 仍只属于当前运行会话；Cookie 的过期时间遵循网页设置。删除项目同时删除该项目的网页存储和日志。设置中的「清除缓存」会清空所有项目的网页数据、Cookie、运行产物与日志，同时递归删除各项目资源根目录的 `cache` 文件夹；删除时不跟随符号链接。其他资源、配置和模板保留，运行产物会在需要时重新生成。

运行会话使用 GeckoSessionSettings.contextId 绑定项目 ID，Cookie 和 DOM 存储由 GeckoView 原生容器隔离。本地服务首次分配端口后持久保存，并设置 SO_REUSEADDR；每次运行保持同一来源，端口被占用时报告错误，不自动改换来源。端口配置不属于缓存，清理时保留。删除项目调用 clearDataForSessionContext；全量清理先确认没有活动会话，再等待 clearData(ALL) 完成。清理与运行准备共用修改锁，日志先经过 flush 屏障，资源服务关闭后不再接受日志回调。

新项目按顺序默认引用 global.css 与 global.js。global.js 提供同步工具与 DOM 操作，缺失时补齐，升级不自动覆盖已保存内容，可在模板页还原为当前安装包版本；旧项目引用列表不自动改写，可通过快速添加引用。

项目配置保存可选 icon 字段，缺省为 code。项目设置使用独立图标与颜色选择面板，草稿确认后回填表单，保存项目后写入配置。360 个图标使用本地 Lucide VectorDrawable，48 种配色保留已有索引顺序；首页和预览使用同一颜色集合，不增加运行时 SVG 解析或网络请求。

`sview.interaction.monitor({ onReady, onError, onClose, onResize })` 同步注册运行事件；再次调用替换整组回调。onResize 提供内容区域宽高（CSS 像素），按帧合并。正常关闭前执行 onClose 的同步收尾，不能依赖它完成长时间异步工作，系统强杀或崩溃无法保证执行。完整参数与示例见应用内交互接口说明。

生命周期使用带会话鉴权的 SSE 推送，只有注册 monitor 才连接，空闲不轮询，不占用资源请求工作线程。就绪由页面完成和窗口首帧共同确认，关闭通知与退场动画并行，确认最多等待 300ms，页面无响应不阻止关闭。错误监听与回调在网页端运行；普通回调未捕获异常交给 monitor.onError，monitor.onError 自身异常只写日志，避免递归错误。

## 项目归档

ProjectJson 统一目录与归档的配置编码。ProjectArchive 在 IO 队列中流式压缩源资源和全局模板快照；项目同名资源优先，配置位于 project.json。导入先解压到独立暂存目录，检查路径、冲突、条目数、解压大小及配置；成功后以新 ID 提交文件并保存配置，生成运行产物。全局快照还原为项目自己的文件，不覆盖共享模板。失败清理暂存文件，现有项目不受影响。远程引用不下载，日志和浏览器存储不属于项目归档。

初始化只加载现有目录并补齐必要模板；不生成示例项目，也不删除升级前已经保存的项目。

## 请求调度与日志背压

网页资源与系统接口使用独立的有界工作队列，定位等较慢调用不会占用文件和关闭确认的请求线程；工作线程空闲后回收。静态文件使用 ETag 重新校验，未变化时返回 304；文本资源显式采用 UTF-8。资源服务准备与窗口入场并行，已初始化的 GeckoRuntime 可直接创建新会话，冷引擎初始化等待一个界面帧，不等待完整入场动画。

网页日志同时最多提交一个请求，单条最多 16000 个 UTF-16 字符，待提交内容上限 64000 字符；超载保留最近内容。批次上限 16000 字符与原生 64 KB 接收上限配合，避免中文按字节截断。关闭屏障复用正在提交的任务，空闲不轮询。

### 页面文本与启动配置

编辑器退出先等待最新内容保存成功，再清空正文、资源列表和控制台；保存失败时留在编辑页。文件与资源读取使用递增序号，退出后的旧结果不再回填。日志详情退出同样释放正文并作废旧读取。首页运行脚本只记录日志文件，不维护隐藏的控制台文本。

`app/src/main/baselineProfiles/` 保存首页启动的 Baseline Profile 与 Startup Profile，分别供 ART 编译和 R8 启动 DEX 布局使用。框架依赖自带的基线仍由 AGP 合并。规则来自正式签名包的首页采样，不提前启动 Gecko。

更新时使用同一次构建的 `mapping.txt` 和设备 `pm dump-profiles --dump-classes-and-methods io.todu.sview` 输出，运行 `scripts/update_startup_profile.py --profile <采样文件> --mapping <映射文件> --output app/src/main/baselineProfiles/baseline-prof.txt`。脚本还原混淆名称，并过滤到首页相关应用类；R8 合并类的方法按原始所属类还原，同名重载保留候选集合。生成后检查规则范围与构建告警，确认启动配置已参与构建。原始采样、测试方法和性能报告保存在源码仓库外。

侧载 APK 由现有 AndroidX ProfileInstaller 安装基线，实际预编译时机由系统调度决定，不能保证安装后第一次打开就完成全部优化。验证按 Android 官方手动流程检查打包配置、安装状态和 `speed-profile` 编译结果；模拟器数字不作为真机性能承诺。

代码编辑高亮在文本变化时先平移、裁剪未改动区间的样式，后台仍合并 90 毫秒内的输入后重新解析。普通输入、粘贴、外部文本更新、撤销和重做共用这条路径；旧解析结果必须与当前文本相同才可发布，避免等待重组时覆盖新样式。超过 10 KB 的文件继续使用纯文本，不参与样式差异扫描。
高亮样式在组合阶段读取，并以样式快照作为 VisualTransformation 的记忆键；异步解析完成即刷新文本布局，不能仅在转换回调中读取 State，否则未编辑时可能一直显示旧的纯文本结果。

遮罩透明度低于 100% 时，点击窗口外遮罩关闭运行窗口。透明度为 100% 时使用工作区内浮层，窗口外触摸交给下层界面，窗口边缘显示灰色 1px 边框；返回键优先关闭运行窗口。切换运行项目时按项目 ID 重建会话，释放前一个项目的资源。

sview.interaction.cornerRadius(value, persist = false) 修改当前窗口圆角，value 使用非负有限 dp 数值，0 为直角。持久化共用项目修改锁，保存成功才更新运行窗口；失败保留原值。monitor 的 onCornerRadius({ cornerRadius }) 在配置值实际变化时推送，相同值不重复推送，订阅时不补发。事件保留配置值，显示时仍裁剪到窗口短边的一半；圆角、网页轮廓及透明模式边框同步更新。

编辑器仅对单次回车补齐缩进，沿用当前行及附近代码的空格或 Tab。JavaScript、CSS、JSON 的未闭合括号及 HTML/XML 普通开始标签增加一级；成对结束符另起一行对齐。字符串、注释及常见 JavaScript 正则中的括号不参与判断。换行与自动补齐共用一次撤销记录，多行粘贴不重新排版。规则计算仅在回车时执行，不增加普通输入的语法解析开销。

首页项目分类、系统接口分类和图标分类使用 HorizontalPager，支持内容区横向拖动与标签点击动画。标签选中状态由当前页统一驱动，标签栏随当前页滚动；各页内容按需组合，网格和列表各自管理滚动状态。首页长按排序期间禁用分页手势，释放或取消拖动后恢复。图标搜索保留当前分类，空结果页仍可滑动切换。

## 局域网编辑器

设置中的“局域网编辑器”由用户手动启动，监听指定端口，使用本次输入的密码登录。密码通过系统密钥加密后保存在本机且不参与备份；会话令牌保存在网页内存中，八小时后过期，停止服务即失效。离开应用自动停止监听，不使用后台服务或唤醒锁。连接采用 HTTP，仅适合可信局域网。

`LanHttpServer` 提供内置网页和经过身份校验的 JSON 接口，限制请求大小、并发数和超时，校验直连地址、Origin 和自定义请求头。`LanWorkspace` 通过现有仓库操作源文件；网页只提交变更文件与已展示的配置字段，不覆盖图标、颜色、变量和引用。修订号不一致时拒绝保存，文件写入失败时恢复本次触及的文件与配置。`WorkspaceModel` 使用原有修改锁与 IO 队列协调手机和网页，手机代码编辑页打开时拒绝远程保存，避免编辑缓冲区回写旧内容。

网页运行按钮等待保存完成后调用手机现有运行窗口，不创建浏览器预览。项目 ZIP 复用 `ProjectArchive`，保留应用导入格式；模板独立导出。单文件上传、下载上限为 16 MB，网页直接编辑的文本单文件上限为 2 MB，首次加载的文本总量上限为 12 MB，超出部分仅提供下载。网页导出的 ZIP 上限为 64 MB，更大的项目通过手机导出。

## FTP 编辑器

手机设置连接分组依次为手表连接、局域网编辑器、FTP 编辑器。`LocalEditorController` 统一两种编辑入口的表单状态，`FtpEditorController` 延迟创建且拒绝手表启动；退出前台时关闭监听、控制连接和数据连接。FTP 密码与网页密码分开加密保存。

`FtpServer` 绑定启动时的局域网 IPv4 地址，最多两个会话；`FtpSession` 实现 UTF-8、被动传输和机器可读目录列表，数据连接只接受控制连接的同一客户端。控制连接空闲超时 120 秒，被动连接等待 15 秒，数据读取超时 30 秒。单文件上限 16 MB，上传完整接收后才向工作区提交，失败不写入源文件；不支持主动模式、续传和加密协议。

`FtpWorkspace` 将虚拟项目目录映射到项目 ID，只公开项目资源与全局模板，拒绝符号链接及越界路径。写入复用仓库原子保存，重命名采用原子替换后废弃派生缓存；主脚本及系统模板不能删除或移走。所有操作经过 `WorkspaceModel` 的修改锁和 IO 队列，与网页保存及手表快照串行，网络传输不持有工作区锁。手机编辑页打开时拒绝 FTP 修改，服务重启后拒绝旧会话请求。FTP 保存不自动触发手表同步，仍使用原有手机快照流程。

## 共享数据库

`SharedDatabase` 在首次读取或写入时打开应用私有的 `shared-values.db`，使用 SQLite 按键保存类型与值。它独立于项目仓库和运行缓存，不参与项目删除、缓存清理或项目 ZIP 导出。设置页与运行窗口使用同一应用级实例，同步锁串行保护读写，更新与键重命名在事务中完成。

脚本 `db.set` 根据值推断类型，对象和数组序列化为 JSON；读取时依据保存的类型恢复，JSON 外观的字符串仍返回字符串。`DatabaseValue` 负责键、类型与大小校验，`DatabaseApiBridge` 在运行接口线程调用存储，避免主线程磁盘访问。网页侧在序列化前拒绝非有限数字、undefined、函数、Symbol、BigInt 和循环引用，避免无声转换。

数据库页只在显示时订阅变更流，不使用轮询。表单复用变量的类型切换与 JSON 编辑器；修改、重命名和删除时校验编辑前的值，避免覆盖脚本在对话框打开期间写入的新值。数据库接口新增后提升运行文档版本，使已有项目的派生入口自动更新。

### 悬浮窗口的内核前后台状态

GeckoRuntime 监听 ProcessLifecycleOwner，只能看到 Activity 的前后台状态。桌面小部件启动的 Activity 退出后，OverlayService 的窗口虽然可见，内核仍会收到暂停通知，并可能触发内存收缩。BrowserEngineVisibility 为悬浮会话额外持有一份配对的 GeckoThread 运行计数，最后一个会话关闭时归还；正常页面仍沿用引擎原有生命周期。

EngineForegroundState 处理重复登记、多窗口和后台首次初始化。Gecko 初次前台通知不会减少暂停计数，因此只对后台初始化时额外补入的计数做一次抵消，避免返回主界面后计数失衡。网络和网页定位监听在进程暂停分发结束后按悬浮窗口是否可见同步；不使用轮询、唤醒锁或重新加载页面。此适配直接调用当前固定 Gecko 依赖公开的 org.mozilla.gecko 方法，升级依赖时须核对生命周期及计数语义。

### 小部件占格校准

Android 的小部件选项提供 dp 尺寸而非实际桌面占格数。配置页由用户确认当前列数和行数，再记录对应尺寸，不再把首次配置读到的最小宽高直接当成标准 2×2。Android 12 以上优先使用 OPTION_APPWIDGET_SIZES，并为每个候选尺寸独立记录横纵校准点；旧桌面使用横竖屏尺寸范围。配置与更新使用同一批尺寸生成 RemoteViews，避免取最小宽度校准却拿另一尺寸布局。

单个校准点保证当前尺寸准确，其他尺寸结合桌面默认边距估算。两个不同占格数的校准点可同时确定格距和边距；更多点按相邻区间插值。每个方向最多四点；同一占格数的尺寸明显改变时，旧方向的校准点失效，防止桌面网格调整后继续使用旧格距。旧的四个逗号分隔尺寸不作为已确认数据，项目顺序仍保留。

校准按小部件实例、应用级屏幕配置及尺寸候选分别保存，折叠和横竖屏不互相套用。没有可信记录时只提供估算，不能承诺在所有桌面上直接从 dp 精确反推占格；需要用户确认当前占格。首次配置尚无尺寸时暂存确认值，桌面报告有效尺寸后再建立基准。恢复小部件时保留项目顺序、清除可能属于其他设备的校准。


## 运行窗口的分配与传输

公共运行桥通过 `/__sview_runtime.js` 同步加载，包含日志、sview 接口、网络和存储封装。每个仓库仅生成一份字节内容，响应支持 ETag 校验；入口不再内嵌整套桥接脚本，也不分别请求网络和存储脚本。脚本按原顺序执行，用户主脚本启动前接口保持完整可用。变更公共脚本时同步递增 RuntimeDocument.REVISION。

网页存储的非空标记在启动准备的 IO 阶段写入，已有标记时不再重复提交；清理后首次运行仍先落盘再打开会话。TextureView 保留圆角、透明与悬浮窗口的合成方式，首帧更新后恢复引擎原始监听，不再逐帧通知 Compose。

原生下载到文件时连续写入临时文件，进度最多约每 100 毫秒发布一次，只保留最新值，不等待网页消费；成功提交目标后发送最终进度。取消和失败唤醒等待方并清理临时文件。流式响应仍保留单块背压，消费完成后复用完整缓冲区。网络与事件发送工作线程空闲后回收。事件历史的数量、容量和重连序号规则不变，补发按小批次发送。

字符串上传按块编码，UTF-8 长度计算不生成完整字节副本，编码边界保留代理对。显式 text 响应在调用 isJson() 时才判断 JSON，有效性判断结果缓存，其他响应类型和错误返回规则不变。请求结束后释放上传正文和进度回调；等待请求用有序集合管理，保留原有排队与取消行为。Cookie 只移除过期内容，不设会导致有效登录状态丢失的新上限；内容及顺序未变化时不重写文件。

设备图片的 DOM 监听按同批新增子树去重，属性变化只处理目标图片。手表预览按现有最大三倍缩放所需像素解码，长图根据短边计算并保持原有 2048 长边上限；手机保持原有解码上限。预览缩放、平移、圆屏适配与窗口裁切规则不变。日志保留对象原有序列化语义，达到现有行长上限后不再格式化后续参数。


## 脚本读取项目日志

`sview.script.log(projectName?)` 返回 `Promise<string>`。省略名称时按运行窗口绑定的项目 ID 读取；名称为完整精确匹配，匹配不到返回 PROJECT_NOT_FOUND，多个匹配返回 PROJECT_NAME_AMBIGUOUS，不接受 ID 对象或以字符串猜测 ID。空白名称、非字符串返回 INVALID_ARGUMENT。

网页封装先等待当前页面 console 缓冲提交，原生再通过 WorkspaceModel 的日志写入屏障和 IO 队列读取完整保留日志。读取持有项目修改锁，避免删除、重命名或手表同步过程中改变目标；不更新日志详情页的 UI 状态。没有日志返回空字符串，已有日志轮转规则保持不变，不采用详情页的 256 KiB 截取限制。跨项目读取只覆盖当前设备，不能获取另一个设备的日志或其他页面尚未发送的 console 缓冲。


## 未捕获错误的转发

普通 Promise 接口沿用拒绝语义，只有浏览器判定未处理时才经 unhandledrejection 进入 monitor.onError，显式 catch 不转发。全局异常和拒绝事件保留 code、message 与 stack；接口或回调兜底还提供 source，type 分别为 interface、callback。错误值的属性读取隔离异常，避免用户抛出的特殊对象破坏监控。

NFC 与服务器运行事件优先交给接口专用 onError，未提供时才交给 monitor。服务启动失败仍拒绝 Promise，已交给专用 onError 的错误对象用 WeakSet 标记，避免全局事件重复上报；没有专用处理器时只沿 Promise 路径传播，调用方仍可 catch。参数校验发生在处理器注册前，继续作为调用失败交给调用方。

普通回调自身抛出的同步或异步异常视为新错误，不因原始错误已处理而丢弃。monitor.onError 自身失败只写日志。关闭回调的新异常允许交给现有 monitor，不等待回调完成，也不延长窗口退出；页面销毁后不能保证继续执行异步错误处理。
