# 分享与外部启动

局域网编辑器的项目设置支持修改共享来源。config 操作未提供 shareSource 时保留原值，显式提供时拒绝未知值；保存后同步更新系统分享入口。

ShareSource 为项目配置的一部分，ProjectJson 同时用于工作区、导出包和手表同步。缺少或未知值均按禁用处理。手机设置展示禁用、全部、文本、文件；手表不展示。WorkspaceModel 观察项目配置并启停 ShareReceiver 别名，不注册逐项目快捷分享目标。别名只处理 SEND、SEND_MULTIPLE；独立 ShareActivity 的 VIEW 过滤器始终处理 sview://task，手机与手表共用。

ShareInput 按实际 URI 列表区分文件与纯文本，读取 EXTRA_STREAM、ClipData、EXTRA_TEXT 和标题。文件需要 content URI，拒绝本应用文件提供器地址，避免外部请求借本应用身份读取其未获得授权的文件。ShareInbox 按 64 KiB 分块复制到 TemporaryFiles 登记的私有目录，最多 16 个文件、合计 32 MiB，按实际读取量复核，失败清理；文本最多 256K 字符。

ShareReceiveModel 保存一次启动的快照，配置变更不重复接收。ShareActivity 在工作区和快照准备完成后筛选项目，单项自动运行，多项供选择。URL 路径按 name 精确匹配项目列表首项，不检查共享来源，share 解码一次后作为文本，title 固定为 URL Schemes。当前运行端口固定，已有运行窗口时拒绝启动，不覆盖既有分享内容。

RuntimeWindow 将快照传给本次 ProjectServer。/__sview_share 返回元数据，编号子路径按流返回文件；不暴露磁盘路径，沿用项目 Cookie 认证并核对 Host、Origin 与请求来源。普通运行返回空对象结构。ScriptShare 首次读取后构造标准 File 并缓存 Promise，重复调用不重复复制字节。异常可重试读取。

关闭接收 Activity 时清理快照，项目退出会结束该 Activity。进程异常退出遗留目录由已有 TemporaryFiles 缓存清理回收；活跃接收目录不会被清理。缓存不在项目资源目录，因此项目导出仅保留共享来源配置。

URL 启动等待同步结束并重新匹配项目，匹配结果变化也会触发启动检查；手表兜底选择使用紧凑单列卡片。
