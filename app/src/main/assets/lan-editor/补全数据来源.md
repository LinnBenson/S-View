# 补全数据来源

CSS 数据来自 https://github.com/mdn/data ，版本 8b46008c1eb6ee5da11f0199bf1a32d450f7642b，遵循同目录 LICENSE-MDN-DATA.txt 中的 CC0 许可。

仅保留属性语法、值关键词、选择器、规则和单位，排除已废弃和厂商前缀属性。再生成时运行 `python3 scripts/generate_editor_completions.py --mdn <mdn-data目录>`；目录需包含 css 数据、LICENSE 和记录提交号的 commit.txt。

S View 候选来自应用内接口帮助；不指定 --mdn 时仅更新 S View 字典。
